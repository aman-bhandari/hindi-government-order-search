# UKIS 2026 — P-001 AI-Powered Government Knowledge Repository (solo entry)

Offline, evidence-first search over Uttarakhand Government Orders (GOs). Ask in Hindi or English; get quoted lines
with GO number, date, page, and the scanned page crop with the supporting words highlighted.

Corpus: Information Technology Department GOs from the official GO MIS portal (go.uk.gov.in), scanned Hindi/English
PDFs, OCR'd locally. Everything runs on one machine; no cloud dependency; optional API switch for the answer model.

Status: step 0.1 (skeleton). Plan: ../documents/p001-plan.md
